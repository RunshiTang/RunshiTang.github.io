# Runshi Tang academicpages overlay

This folder is a content overlay prepared for the official `academicpages/academicpages.github.io` template.

## What is included

- `_config.yml` customized for Runshi Tang
- `_data/navigation.yml`
- `_pages/about.md`
- `_pages/publications.html`
- `_pages/awards.md`
- `_pages/cv.md`
- `_publications/*.md`
- `images/profile.jpg`
- `files/CV_Runshi_Tang.pdf`

## How to use

1. Create a fresh GitHub repository from the official Academic Pages template.
2. Copy the contents of this folder into that new repository, overwriting the default files where paths match.
3. Commit and push.
4. In `_config.yml`, double-check `url`, `repository`, and any profile links you want to add.
5. Optionally remove unused directories and pages from the template if you do not want blog posts, talks, teaching, or portfolio pages.

## Suggested next edits

- Add Google Scholar / ORCID / LinkedIn links in `_config.yml`.
- Add talks and teaching entries if you want to use those template sections.
- Refine publication dates and add abstracts to publication pages.
